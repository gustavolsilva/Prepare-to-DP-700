Unidade comprimida de consulta rápida e revisão pré-prova DP-700

1. Conceitos Fundamentais de Armazenamento e Computação

Termo Categoria Definição Clara (Para Iniciantes e Liderança) Equivalente / Contexto Técnico
OLTP Conceito Processamento transacional online. Otimizado para milhares de operações rápidas de linha única (INSERT, UPDATE). PostgreSQL, MySQL, SQL Server transacional, ERPs.
OLAP Conceito Processamento analítico online. Otimizado para agregar milhões de linhas lendo apenas colunas específicas. Data Warehouses, Data Lakes, Fabric Lakehouse/Warehouse.
OneLake Storage O data lake corporativo único e lógico de todo o tenant da organização ("O OneDrive para dados analíticos"). Construído sobre ADLS Gen2; acessível nativamente via protocolo ABFS (Azure Blob File System).
Capacity Unit (CU) Compute Unidade de medida de poder computacional compartilhada por todas as cargas de trabalho no Fabric. Equivalente aos vCores/DBUs unificados. SKUs variam de F2 (2 CUs) até F2048.
Smoothing FinOps Mecanismo que distribui picos curtos de uso de computação ao longo de uma janela móvel de 24 horas. Evita contratação de capacidade pelo pico máximo; reduz custos operacionais.
Throttling FinOps Penalização automática imposta quando a capacidade excede 100% dos limites acumulados de CUs. Fases: Atraso interativo (60s) → Rejeição interativa → Rejeição de jobs de background.

2. Motores Analíticos (Engines) do Fabric

Motor / Artefato Categoria Definição e Quando Usar Linguagens Suportadas
Lakehouse Engine Armazenamento aberto em pastas e tabelas Delta Lake. Ideal para engenharia de dados exploratória e pipelines Spark. PySpark, Spark SQL, Scala, R, e T-SQL somente leitura via SQL Endpoint.
Warehouse Engine Data warehouse relacional SaaS com suporte transacional multi-tabela completo (ACID) gravando nativamente em Delta. T-SQL completo (DDL, DML, transações explícitas BEGIN/COMMIT).
Eventhouse (KQL DB) Engine Motor analítico colunar ultra-rápido otimizado para ingestão contínua de streaming, logs, métricas e séries temporais. KQL (Kusto Query Language) e subconjunto de T-SQL.
Data Factory (Pipelines) Orchestration Motor de orquestração de fluxos de dados baseado em atividades (Copy, Lookup, Notebook, ForEach, Web). Interface gráfica no-code / low-code com expressões dinâmicas em JSON.
Dataflows Gen2 Ingestion Transformação visual de dados baseada em Power Query com suporte a publicação direta no OneLake e staging Lakehouse. Linguagem M (Power Query).

3. Formatos, Acelerações e Governança

Recurso Categoria O que faz na prática Impacto DP-700 / Produção
V-Order Optimization Otimização no momento da escrita de arquivos Parquet que reordena dados em row-groups para leitura ultrarrápida. Reduz tempo de query em Spark e SQL; essencial para viabilizar Direct Lake sem fallback.
OneLake Shortcut Virtualization Ponteiro virtual (link simbólico) para dados externos (S3, ADLS Gen2, GCS) sem mover ou copiar fisicamente arquivos. Evita custos de tráfego de dados e elimina pipelines ETL redundantes de cópia.
Database Mirroring Zero-ETL Replicação contínua e quase em tempo real de bases operacionais (Azure SQL, Snowflake, Cosmos DB) para Delta no OneLake. Zero pipeline de extração; dados sincronizados por CDC gerenciado pela Microsoft.
Direct Lake BI / Serving Modo de conexão do Power BI que lê tabelas Delta Parquet diretamente do OneLake na memória sem importar nem consultar via SQL. Performance idêntica ao Import Mode com a escala de dados e atualização do DirectQuery.
Domain Governance Agrupamento lógico de workspaces para apoiar a arquitetura de Data Mesh centrada em domínios de negócio. Permite designar donos de domínio e políticas centralizadas de conformidade.
