# Baseline: Experiência Sênior Databricks & Requisito Multi-Público

O usuário possui mais de 10 anos de experiência em Engenharia de Dados, certificação Databricks Data Engineer Professional e domínio pleno de Apache Spark, Delta Lake, SQL Server e arquitetura Medallion.

Ao mesmo tempo, estabeleceu que este curso deve ser construído como um produto educacional completo, atendendo desde iniciantes com 0 anos de dados (Júnior/Transição) até profissionais Staff e C-Level.

### Implicações
- As lições devem utilizar a abordagem de **Progressive Disclosure** (Multi-Lens) em 4 camadas de profundidade (Júnior, Sênior, Staff, C-Level).
- A base técnica sólida permite aprofundamento rigoroso em baixo nível (Velox, Native Execution Engine, OneLake ABFS, algoritmos de V-Order e métricas de CU).
- Nenhuma explicação básica deve ser omitida para o público iniciante, mas deve ser estruturada modularmente para não interromper a fluidez de leitores avançados.
