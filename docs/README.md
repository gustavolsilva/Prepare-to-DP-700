# 📚 Centro de Documentação: Prepare to DP-700

Bem-vindo ao centro de documentação técnica, pedagógica e arquitetural do **Prepare to DP-700**.

Para manter a raiz do repositório limpa, focada e contendo apenas os arquivos estritamente necessários para a execução e uso do projeto, todas as especificações, planejamentos, históricos e guias foram organizados neste diretório `docs/`.

---

## 🗂️ Estrutura de Documentação

### 1. Guias Principais de Arquitetura & Manutenção
* **[`ARCHITECTURE.md`](ARCHITECTURE.md):**
  * Detalhamento da arquitetura web padronizada (Vanilla HTML5/CSS3/ES6+).
  * O modelo pedagógico multissensorial **VARK** (Visual, Aural, Read/Write, Kinesthetic).
  * Funcionamento das **6 Lentes Pedagógicas de Senioridade** com sincronização global em `localStorage`.
  * Design tokens inspirados no template **Figma TOTC E-Learning**.
  * Arquitetura do **Motor de Simulados Pearson VUE** (Single-Choice, Multi-Select e Split-Screen Case Studies).
  * Mapeamento com os 3 Domínios oficiais do Guia de Estudos do DP-700 da Microsoft.

* **[`MAINTAINERS.md`](MAINTAINERS.md):**
  * Guia prático para contribuidores, mantenedores e educadores.
  * Checklist para criar novas lições em HTML sem quebrar o layout.
  * Padrão de desenvolvimento para novos laboratórios práticos em Python (`./labs/`).
  * Como formatar e registrar novas questões no banco oficial (`assets/exam-questions.js`).
  * Como expandir o dicionário fonético e gerar novas narrações neurais.

---

### 3. Diário de Bordo & Registros de Aprendizado (`docs/learning-records/`)
* **[`learning-records/README.md`](learning-records/README.md):** Índice cronológico completo com links para cada um dos 17 registros de aprendizado.
